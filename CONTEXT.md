# Vibe Code Fest Badges

This context describes how participants are identified and how badges are constrained across the Vibe Code Fest badge generation flows.

## Language

**Web Participant**:
A person allowed to use the web badge generator because their email is approved for the Vibe Code Fest event in Luma. The canonical identity for the web flow is the Luma `user_email`, looked up as the Luma guest identifier within the Vibe Code Fest Luma event; each Web Participant can create at most one web Badge.
_Avoid_: Anonymous user, account

**Badge**:
The final generated Vibe Code Fest profile image that a participant can save and share.
_Avoid_: Batch

**Badge Wall**:
The public gallery of generated Badges. It includes Badges from both WhatsApp and web origins while keeping the same visual presentation for all Badges.
_Avoid_: WhatsApp wall, web gallery
